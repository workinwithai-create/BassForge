# BassForge

Focused bassline companion for music makers.

Set BPM (60-180), key, bars. Play live bass grooves that follow your progression. Changes apply live. Export WAV + MIDI that drop perfectly on the DAW grid.

## Pricing
Recommended: one-time $19. Best place to sell: Gumroad or Lemon Squeezy (license key gate). Or free with WorkinWithAI entitlement.

## Compliance
Follows WorkinWithAI Audio Engine Rules 1-9. Samples in /public/samples/. No @main. Deterministic exports.

## Acceptance
(1) Export 92 BPM 8 bars 48kHz: 1001739 samples, transient at 0.
(2) Loops clean in DAW.
(3) Tab switch stops cleanly.
(4) Live changes within one bar.
(5) Missing sample named in UI.
(6) Pads sustain (bass holds).
(7) No @main, no Math.random in export, names match.
